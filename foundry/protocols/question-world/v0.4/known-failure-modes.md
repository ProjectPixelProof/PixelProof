# Known failure modes under protocol v0.4

- A cosmetic re-skin can acquire a new taxonomy string. Compare mechanisms, not
  submitted names.
- A high semantic-similarity score is a review trigger, not proof of duplication.
- An agent can omit an inconvenient neighbor. Independent retrieval checks that
  the top retrieved known world appears in the submitted contrast.
- `not_applicable` is not permission to hide a label variable. Gold-only scene
  fields, sampled pixel collisions with different answers, or nonempty declared
  transformations fail the latent-alias gate.
- Requiring fake nuisance fields rewards ceremony. Do not add unused latent tags
  merely to manufacture a symmetry.
- An oracle can pass convenient seeds and fail the submitted gallery. Probe exact
  evidence plus multiple deterministic stress ranges.
- Draw order and occlusion can break color-mask geometry, especially line or
  component fits.
- A trace can be batch-written. Treat it as artifact history, not private
  reasoning or chain-of-thought.
- A 45-minute timeout is a cap, not a requirement to consume wall time.
- No machine reward, including semantic retrieval, performs human admission.
