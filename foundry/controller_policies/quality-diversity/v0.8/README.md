# Quality diversity policy v0.8

`quality-diversity@0.8.0` adds gallery-side descriptor preview to the v0.7
joint-cell steering policy. The target, nine-cell mask, adaptive scheduler,
semantic ceiling, behavioral-distance competition, and protected
`pixel-oracle-support@0.5.0` attestation are unchanged.

The agent receives the same deterministic descriptor implementation as a
development tool and runs it only on its self-generated gallery. It must repair
the renderer, sampling margins, or inverse mechanism until the preview is
complete, matches the requested cell, and meets the frozen stability floor.
The preview cannot admit an elite: after networked-agent teardown, the protected
verifier reruns the descriptor independently on unseen stress seeds. Scientific
validity remains entirely separate from archive placement.

This version responds to the v0.7 canary, where both candidates were valid but
neither reached the requested `distributed × compact` cell. One was stably
off-target and the other exposed too little ablation-sensitive support to be
classified. The intervention is prospective and keeps those records immutable.
