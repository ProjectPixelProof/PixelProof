# Audited transactional episodic strategy v0.7

V0.7 preserves the v0.6 scientific transaction and adds prospective paper-run
instrumentation. A container-local append-only phase ledger records durable
staging, every public-gate attempt, explicit repair starts, and the final clean
envelope commit. The controller binds those observations to Harbor lifecycle
timestamps, provider usage, protected verdicts, packet hashes, and run
configuration in a reconciled session-end evidence manifest.

The phase tools never award eligibility and are visible to the builder. Hidden
registry checks and admission remain protected and human-only. Missing or
malformed phase evidence makes a run comparison-ineligible; it does not turn a
scientifically failing candidate into an infrastructure pass.

V0.6 and all campaigns that used it remain immutable. Confirmatory paper runs
must use v0.7 consistently across agents and profiles.
